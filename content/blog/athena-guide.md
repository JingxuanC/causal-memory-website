ATHENA · 使用教程

AI 金融研究 Agent · 工作区制研究 · PTC 代码执行 · 自动盯盘 · `athena.causal-memory.com`

大多数「AI 炒股」产品是聊天机器人：你问一句，它凭记忆答一句。Athena 不一样——它是一个**会写代码的金融研究员**。你给它一个问题，它会在隔离的沙箱环境里真正动手：拉行情、跑 pandas、画图、建估值模型、写回测，最后把报告存进你的工作区。明天再来，它还记得昨天分析到哪。

这篇教程按真实使用路径写，读完你会用 80% 的日常功能。

## 01先建立直觉：它和聊天 AI 有什么区别

| | 普通 AI 聊天 | Athena |
|---|---|---|
| 数据 | 靠模型记忆，可能过时或编造 | 实时拉取真实行情与财报数据 |
| 计算 | 「口算」，长数字经常错 | 写 Python 代码在沙箱里精确计算 |
| 结果 | 聊完即走 | 文件、图表、模型保存在工作区，随时继续 |
| 主动性 | 你问它才答 | 定时任务到点自动干活，触发器盯盘 |

背后的架构叫 PTC（Programmatic Tool Calling）：Agent 不把原始数据塞进对话，而是**写代码处理数据、只把结论带回来**。十年日线三万行，直接喂给模型必死；写成 pandas 代码处理，又快又准。这是量化场景能不能用起来的分水岭。

## 03第一次研究：5 分钟跑通全流程

**第 1 步**：左侧「新对话」或新建一个工作区，比如「宁德时代研究」。

> 工作区 = 一个研究项目的文件夹。里面所有数据、图表、报告都会保存，Agent 还维护一份 `agent.md` 笔记记录研究进展——这是 Athena 和普通聊天最大的区别：**研究是可累积的资产**。

**第 2 步**：输入第一个任务，比如：

```
帮我分析宁德时代(300750)最近一年的走势，
画出 K 线和成交量，找出涨幅最大的 5 个交易日并分析原因
```

**第 3 步**：看它干活。Agent 会自己写代码 → 拉数据 → 画图 → 分析。所有产物在「工作区文件」面板里，可预览可下载。

![](/blog/athena/img3.png)

**图 3** · Agent 可以直接在行情图上标注：支撑位、压力位、止损线、关键事件——说人话不如画出来

## 04两种模式：什么时候用哪个

输入框上方有 **PTC** 开关和模型选择器。判断标准一句话：

> **需要「算」和「画」的用 PTC 工作区；只需要「聊」的用 Flash。**

| | ⚡ Flash 快捷模式 | 🔬 PTC 深度研究 |
|---|---|---|
| 适合 | 概念解释、快速查询、新闻摘要 | 数据分析、画图、回测、估值建模 |
| 代码执行 | 无 | 完整沙箱，真实运行 Python |
| 速度 | 秒回 | 几分钟（它在真跑代码） |
| 例子 | 「PE 和 PB 有什么区别」 | 「回测这个双均线策略」 |

## 05四个真实场景（话术可直接复制）

### 场景一：个股深度研究

```
帮我深度分析贵州茅台(600519)：
1. 最近 3 年营收、净利润、毛利率趋势，画图
2. 当前 PE/PB 和过去 5 年历史分位对比
3. 最近一期财报的关键变化
4. 写一份一页纸投资要点，存到工作区
```

### 场景二：策略回测

```
回测沪深300双均线策略：20日线上穿60日线买入，下穿卖出，
最近5年，给年化收益、最大回撤、夏普比率，
和买入持有对比，画净值曲线
```

### 场景三：财报季跟踪（工作区的真正威力）

第一次让 Agent 建好估值模型并保存；财报出来后直接说「Q3 财报出了，更新模型，对比我们的假设，估值要不要调」——它会读之前的模型**接着做**，而不是从头再来。

### 场景四：HTML 图文报告

深入的回答可以让 Agent 产出单文件 HTML 报告：图表、表格、可交互内容打包在一起，可以直接发给同事。

## 06自动化：让它替你盯盘

「自动化」页有五个现成模板：自定义、价格提醒+分析、早盘简报、每周投资组合回顾、财报追踪。

![](/blog/athena/img4.png)

**图 6** · 自动化面板：早盘简报、净值日报、价格触发器，一次设置持续运行

两种触发方式：

- **定时（cron）**：「每天早上 9 点给我一份 A 股盘前简报」——到点自动跑，结果进消息流
- **价格触发**：「宁德时代涨超 5% 或跌破 180 元提醒我」——后台每 30 秒轮询，命中即触发一次完整分析

也可以直接在对话里说：「帮我设置每天早上 9 点的盘前简报」，Agent 会替你建好任务。任务随时可以暂停、恢复、删除。

## 07进阶：插件与技能

「插件」页是 Athena 的能力扩展中心，分两层：

- **MCP 服务器**：数据源和外部工具——行情、新闻、因子挖掘、爬虫，甚至券商账户（moomoo 等，按需开启）
- **技能（Skills）**：预置的专业工作流，比如缠论结构分析（chan-analysis）、图表标注（chart-annotation）、市场监控（market-watch）。对话里输入 `/` 调用

![](/blog/athena/img8.png)

**图 7** · 插件中心：上传一个 SKILL.md 的 zip 就能教 Agent 一个新工作流

你的 API 密钥等敏感信息存「工作区设置 → Vault」，加密保存，Agent 代码通过 `from vault import get` 调用，密钥永远不会出现在对话里。

## 09常见问题

**数据是实时的吗？** 行情来自 Yahoo Finance / FMP 等数据源，约 15 分钟延迟、分钟级刷新。做研究够用，高频交易不行。

**支持哪些市场？** A 股、港股、美股。A 股有专门的中文新闻源，美股数据最全。

**它会自动帮我交易吗？** 不会。Athena 只做研究和分析，交易决策永远由你做。所有内容仅供参考，不构成投资建议。

**为什么有时要等几分钟？** PTC 模式下它在真实执行代码：拉数据、计算、画图。「等它跑完」比「秒回但瞎编」可靠得多。

**研究做了一半能明天继续吗？** 能，这正是工作区的意义。
